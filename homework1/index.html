01 / FUNDAMENTALS

The mathematics of a public key

A deliberately small curve

y² ≡ x³ + 7 (mod 17)

All coordinates are integers modulo 17. A point belongs to the curve only when it satisfies the equation. We use the base point G = (1, 5) and private scalar k = 6.

The public point Q = kG is formed by repeatedly adding G to itself. The actual Ethereum curve, secp256k1, uses a vastly larger prime field.

Point addition

For P = (x₁,y₁) and R = (x₂,y₂), compute a slope λ with modular division (multiplication by a modular inverse):

P ≠ R: λ = (y₂−y₁)/(x₂−x₁) mod 17
P = R: λ = (3x₁²)/(2y₁) mod 17

x₃ = λ²−x₁−x₂ mod 17
y₃ = λ(x₁−x₃)−y₁ mod 17

Opposite points add to the point at infinity O, the group identity. In a finite field the familiar geometric line is only an analogy.

    04 / INTERPRETATION

    What do these statistics mean?

    Meaningful for public-key cryptography

    • Determinism: a fixed k and G always produce the same Q.
    • Efficient forward direction: double-and-add computes kG in O(log k) group operations.
    • Hard inversion at scale: recovering k from Q on properly chosen large curves is the elliptic-curve discrete logarithm problem (ECDLP).
    • Uniformity over the subgroup: if k is uniform modulo the group order, the resulting group element is uniform over that subgroup.

    Not equivalent to a hash function

    • Avalanche is not required: scalar multiplication is algebraically structured. kG and (k+1)G differ by exactly G.
    • Coordinates are constrained: curve points cannot be arbitrary independent x/y bit strings.
    • Correlations: a low Pearson correlation with scalar values would not imply cryptographic security.
    • No hash-style compression: the map from scalars modulo the subgroup order to group points is injective; repeating points for k+n reflects modular periodicity, not a hash collision.

    Conclusion

    The experiment demonstrates a deterministic mathematical mapping that is easy to compute and reversible by brute force on this tiny curve. Coordinate histograms and bit statistics describe the output structure, but cannot establish resistance to discrete-logarithm attacks. Ethereum combines scalar multiplication on secp256k1 with Keccak-256 hashing for address derivation: two primitives serving different purposes.
