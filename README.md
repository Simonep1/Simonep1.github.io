# Statistics Lab — GitHub Pages

A responsive three-page Statistics homework portfolio built with plain HTML, CSS, and browser JavaScript.

## Structure

- `index.html` — course homepage
- `assets/styles.css` — shared styling
- `homework1/index.html` — toy elliptic-curve calculator and statistics
- `homework1/hw1.js` — finite-field operations and experiment logic
- `homework2/index.html` — Ethereum wallet standards and live demonstration
- `homework2/crypto.js` — educational BIP-39, BIP-32, secp256k1 and Keccak-256 implementations
- `homework2/hw2.js` — controls, hash comparison, statistics

## How to publish

Copy **the contents of this folder** into the root of your GitHub repository (keep folders intact). Then open **Settings → Pages → Deploy from a branch → main → /(root)** and Save. The homepage becomes available at the GitHub Pages address for that repository.

The links are relative, so the project works both as a user site (`username.github.io`) and a project site (`username.github.io/repository-name/`).

## Local viewing

Homework 1 and the homepage should work by opening `index.html` directly. For Homework 2, start a local web server so the ES module and browser Web Crypto APIs load consistently:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Accuracy and limits

- Homework 1 uses `y² = x³ + 7 (mod 17)`, with the suggested `G = (1,5)` and `k = 6`, resulting in `Q = (5,8)`. Note the subgroup generated by this G has **order 9**, not 18; the entire curve has 18 points counting the infinity point.
- Homework 2 uses the **public BIP-39 test mnemonic only**. It intentionally does not accept private recovery phrases. Never reuse the demo mnemonic for funds.
- The cryptographic algorithms in `crypto.js` are an educational implementation and are **not audited for production use**. Ethereum accounts may use different derivation paths depending on wallet software.
- Statistical measurements are exploratory and cannot prove cryptographic security.
