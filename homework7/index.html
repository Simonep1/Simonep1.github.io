Statistical Independence

A simple example using two categorical variables and Pearson's chi-square test.

1. What does independence mean?

In probability, two variables X and F are independent if the joint probability is the product of the marginal probabilities for every pair of values:

P(X = x, F = f) = P(X = x) · P(F = f)

This is equivalent to P(F = f | X = x) = P(F = f), whenever P(X = x) > 0. Knowing X does not change the distribution of F.

In statistics, we estimate these probabilities from data. Even if two variables are independent in the population, the sample frequencies will not usually match exactly. The chi-square test checks whether the observed differences are large enough to question independence.

4. Expected frequencies under independence

    
If X and F were independent, the expected number of observations in cell (i, j) would be:

    
Eij = (row totali × column totalj) / n

    

    
For example, the expected number of stable Wi-Fi connections is (20 × 24) / 40 = 12, compared with 8 observed.


    
5. Chi-square test

    
We compare observed counts (O) with expected counts (E) using Pearson's chi-square statistic:

    
χ² = Σ (Oij − Eij)² / Eij

6. Conclusion

    

    
The interruption rate is different between Wi-Fi and Ethernet in this sample. However, a statistical association does not prove causation. Signal quality, equipment and other factors could influence connection stability. Since this dataset is simulated, the conclusion only illustrates the statistical method; it is not a claim about real connections.
