Exercise 1 — Riemann and Lebesgue integration

In this exercise I compare two ways of approximating an integral. Riemann sums divide the domain into intervals, while Lebesgue integration groups points according to the values of the function.

Riemann (midpoint rule)
RN = Δx Σ f(a + (i + ½)Δx)

Here Δx = (b − a)/N.

Lebesgue (value levels)
∫f = ∫0∞ μ({x : f(x) > t}) dt

For nonnegative functions, I approximate the second integral using K levels of the range.

For the Lebesgue calculation I use the known length of each superlevel set m(t) = μ({x : f(x) > t}). This is important: simply sampling the domain and sorting the results would not compute the preimage measures exactly. For example, for f(x) = x², m(t) = 1 − √t for 0 ≤ t ≤ 1.

Observations

For the continuous functions, both approaches tend to the same integral. The midpoint Riemann rule is often more accurate with the same number of partitions. The Lebesgue approach can be slower if finding the measure of the preimage is difficult.

The step functions are still Riemann-integrable, even though they have a jump. The function 1/√x is unbounded near zero: its improper integral is 2. In the numerical Lebesgue method I cut the range at a finite height and add the remaining tail using the known formula for its measure.

Dirichlet's function is different. It equals 1 on rational numbers and 0 on irrational numbers. It has no Riemann integral, since every interval contains both types of numbers, but its Lebesgue integral is 0 because the rationals have measure zero. Thomae's function is Riemann-integrable and Lebesgue-integrable, with integral 0. Although it is discontinuous at every rational point, it is continuous at every irrational point.

For Dirichlet and Thomae, the program uses exact rational grid points for the Riemann sums. Testing whether a JavaScript decimal number is rational would be misleading.

Exercise 2 — Numerical computation of the normal CDF

For a standard normal variable Z, the cumulative distribution function is the probability that Z ≤ z:

Φ(z) = (1/√(2π)) ∫−∞z e−t²/2 dt

The Gaussian function does not have an elementary antiderivative. Liouville's theorem gives a way to establish this: in this case, an elementary antiderivative would require a rational function r satisfying r′(x) − xr(x) = 1. Such a rational function does not exist (a pole cannot cancel, and a polynomial gives the wrong degree).

We can still write an exact expression using the error function:

erf(u) = (2/√π) ∫0u e−t² dt    Φ(z) = ½[1 + erf(z/√2)]

However, to obtain a decimal value, erf must also be evaluated numerically. I implemented three methods:

  1. Trapezoidal rule: numerical integration between 0 and z, using symmetry.
  2. Simpson's rule: a more accurate integration rule for smooth functions.
  3. Power series: expansion of erf around zero. It works well near zero, but loses precision for large negative z because of cancellation.

Accuracy and efficiency

Trapezoidal and Simpson integration need N + 1 evaluations of the normal density. Their theoretical errors decrease respectively as 1/N² and 1/N⁴ for a fixed integration interval. For large negative values, a small absolute error may still be a large relative error. This is a limitation of computing Φ(z) as ½ plus or minus an integral. For very small tail probabilities, a dedicated erfc or tail approximation would be preferable.

Conclusion

The two definitions of integration agree on Riemann-integrable functions, but they approach the calculation differently. The examples of Dirichlet and Thomae show why the Lebesgue definition is more general. For the normal CDF, Simpson's rule gives good accuracy without too many intervals, while the series is useful near zero. The best method depends on the function and on the precision we need.
