Exercise one

Riemann vs. Lebesgue integration

I used several functions whose integrals are known, so that the numerical approximations can be checked instead of only compared to one another. The selection includes smooth curves, jumps, an unbounded function and two pathological examples.

Partition the x-axis

Riemann approach

Divide [a,b] into N equal intervals of width Δx and take one value in each interval. For the main experiment I use midpoint tags.

RN = Δx · Σi=0…N−1 f(a + (i + ½)Δx)

For smooth functions midpoint sums are usually second-order accurate. This does not hold automatically at discontinuities or singularities.

Partition the y-axis

Lebesgue approach

Group domain points by their function values. Each group contributes its value multiplied by the measure of its preimage.

L ≈ Σj yj · μ({x : f(x) ∈ Bj})

For nonnegative functions I calculate the measure of superlevel sets, m(t) = μ({x : f(x) > t}).

How I implemented the range partition

For a nonnegative function the layer-cake identity gives ∫f(x)dx = ∫0∞ m(t)dt. For a bounded function with maximum height H, use the levels yj = jH/K, with δ = H/K. Since m(t) is decreasing, the following are genuine lower and upper bounds when m(t) is known:

Llow = δ Σj=1…K m(jδ)  ≤  ∫f  ≤  δ Σj=0…K−1 m(jδ) = Lup

The displayed Lebesgue estimate is the midpoint of these bounds. For the ordinary functions, the measure m(t) is found algebraically; for sin(x)/x it is obtained by bisection. I also include a sampled range-binning estimate, using randomised stratified probes to estimate the measures. That sampled variant is only an approximation inspired by Lebesgue integration: its accuracy depends on the domain samples and it cannot correctly recognise rational versus irrational real numbers.

Special case: for 1/√x the range is unbounded. I truncate the levels at H = √K and add the analytically known tail ∫H∞ m(t)dt = 1/H. This is an explicit correction, not something a generic numerical method would know without additional information.

Why the pathological examples matter

Not Riemann-integrable

Dirichlet function

It equals 1 on rational numbers and 0 on irrational numbers. Every interval contains both: all lower Darboux sums are 0, all upper ones are 1. Midpoints of a rational grid give 1, while irrational tags give 0. Both are possible sampled sums; neither is a Riemann integral. Since rationals have measure zero, the Lebesgue integral is exactly 0.

Riemann-integrable after all

Thomae's function

At a reduced rational p/q its value is 1/q; at irrational numbers it is 0. The discontinuity set is the rationals, which have measure zero. It is therefore Riemann-integrable by Lebesgue's criterion, with integral 0. Rational grid samples can still give a positive answer at finite N, but those values decrease as the partition is refined.

Improper but integrable

1/√x

The function is unbounded near x = 0 and is not Riemann-integrable in the ordinary bounded-function sense on [0,1]. Its improper Riemann integral and its Lebesgue integral both equal 2. Ordinary left-endpoint evaluation fails at 0; midpoint sums converge slowly, and range levels require a tail treatment.

Single discontinuity

Step functions

A jump at x = ½ does not prevent Riemann integrability. Both methods converge to the same area. If an even partition happens to align perfectly with the jump, a midpoint sum can already be exact, but that is a property of the chosen grid, not a general guarantee.

Conclusion for exercise 1. On the bounded Riemann-integrable functions, both constructions approach the same integral. For smooth functions the midpoint rule usually gives more accuracy per function evaluation; the range-based construction is valuable when measures of level sets are accessible, and it still works for measurable functions that have no Riemann integral. Counting function evaluations alone is not enough to compare costs: obtaining a preimage measure may itself be difficult.

Exercise two

Computing the standard normal CDF

For a standard normal variable Z, the CDF Φ(z) is the probability P(Z ≤ z). The density is symmetric about zero, so it is enough to integrate from 0 to |z|, provided we are careful when subtracting probabilities close to ½.

φ(z) = exp(−z²/2)/√(2π)    Φ(z) = ∫−∞z φ(t)dt = ½[1 + erf(z/√2)] = ½ erfc(−z/√2)

Why there is no elementary antiderivative

The Gaussian integral exists, but the indefinite integral of exp(−x²/2) cannot be written as a finite combination of elementary functions. This is a consequence of Liouville's theorem on elementary antiderivatives (not the similarly named theorem from complex analysis).

Short argument

For an integrand of the form exp(g(x)) with polynomial g, the relevant consequence of Liouville's theorem says that an elementary primitive would require a rational function r(x) satisfying r′(x) + g′(x)r(x) = 1. Here g(x) = −x²/2, so the equation becomes:

r′(x) − xr(x) = 1

A rational solution cannot have a finite pole: at a pole of order m, r′ has a pole of order m+1, which −xr cannot cancel. Therefore r would have to be a polynomial. But if r is a nonzero polynomial of degree d, the left side has degree d+1, so it cannot equal the constant 1; the zero polynomial also fails. Thus no rational r exists, ruling out an elementary antiderivative.

The error function is defined by erf(u) = (2/√π)∫0u exp(−t²)dt. It gives Φ an exact expression, but the answer still needs a numerical algorithm to produce decimal values. Equivalently, using erfc is especially useful for small tail probabilities because it avoids subtracting two nearly equal floating-point numbers.

Methods implemented

A
Composite trapezoidal rule

Apply the trapezoid rule to ∫0z φ(t)dt, then add ½. Expected error O(N−2).

B
Composite Simpson's rule

The same integral with Simpson weights 1–4–2–…–4–1. N must be even; for smooth integrands the error is O(N−4).

C
Power series of erf

Use erf(u) = (2/√π)Σk≥0(−1)ku2k+1/(k!(2k+1)). Fast near the centre, but the alternating terms lead to cancellation for large |z|.

D
Positive-term series + tail continued fraction

For |z| < 2, use Φ(z) = ½ + φ(z)Σk≥0z2k+1/(2k+1)!!. For |z| ≥ 2, compute the smaller tail directly from a continued fraction and use symmetry. This is my main practical method.

E
erf polynomial approximation

Use the classic five-coefficient approximation in Abramowitz & Stegun, formula 7.1.26. It is very fast, but has a fixed approximation error.

For a = |z| ≥ 2:   Φ(−a) ≈ φ(a) / [ a + 1/(a + 2/(a + 3/(a + …))) ]

Important: a formula that computes a tiny left-tail probability as ½ minus an integral, or as 1 − Φ(a), can lose almost all significant digits. The continued fraction instead computes the small tail directly. Near zero, the power series is more effective.

Theoretical orders are 2 for trapezoid and 4 for Simpson. Once errors approach the precision of JavaScript's 64-bit floating-point numbers, increasing N may stop helping. A highly accurate series or tail formula often reaches a useful precision with much less work than integrating hundreds of subintervals.

Conclusion for exercise 2. Simpson's rule is a reliable way to evaluate Φ in the central region, and its accuracy improves quickly as the grid is refined. A series works well near zero. In the tails, however, precision is not just about using more terms: the form of the calculation matters. Directly evaluating the small complementary probability avoids subtractive cancellation and preserves much better relative accuracy.

Sources and reproducibility

Everything on this page runs locally in plain JavaScript, with no external charting libraries or server calls. The displayed computations are performed when the page loads or when an input changes. For repeatability, the sampled range experiment uses a deterministic pseudo-random generator with a fixed seed. Timings are intentionally measured on the reader's machine rather than reported as universal performance numbers.
