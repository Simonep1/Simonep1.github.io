01 — Welford's recurrence formulas

Suppose that x1, …, xn are the observations. We want to update the mean and the sum of squared deviations whenever a new observation arrives, without going through the previous data again.

Knuth's recurrence for the mean is:

δn = xn − x̄n−1 x̄n = x̄n−1 + δn / n

Recurrence for the sum of squares (SS)

Define SSn = ∑i=1n (xi − x̄n)². Since the previous deviations from their mean sum to zero, expanding the squares gives:

SSn = SSn−1 + (n−1)(x̄n − x̄n−1)² + (xn − x̄n)² = SSn−1 + [(n−1)/n] δn² = SSn−1 + δn(xn − x̄n)

The last step follows from xn − x̄n = [(n−1)/n]δn. Initially, x̄0 = 0 and SS0 = 0.

Recurrence for the sampling variance

The sampling (unbiased) variance is sn² = SSn / (n−1), for n ≥ 2. Substituting the recurrence for SS:

sn² = [(n−2)/(n−1)] sn−1² + δn² / n   (n ≥ 3)

For n = 2, we directly use s2² = SS2. The sampling variance is undefined for a single observation.

JavaScript implementation

The update itself consists of three lines. At each step count is the number of observations processed, including the new one.

Welford update 
function welford(scores) {
  let mean = 0, SS = 0;
  for (let i = 0; i < scores.length; i++) {
    const count = i + 1;
    const delta = scores[i] - mean;
    mean += delta / count;
    SS += delta * (scores[i] - mean);
  }
  return {
    mean,
    variance: scores.length > 1 ? SS / (scores.length - 1) : null
  };
}

Only the mean, SS and the observation count need to be stored. The sampling variance is obtained from SS at the end.

02 — Sampling mean and variance

Distribution and theoretical values

As an extension of Homework 4, each of the m hackers attempts n systems. Every attempt receives an independent integer score between 0 and 10. I use a discrete uniform distribution: all 11 scores are equally likely.

P(X = k) = 1/11,   k ∈ {0, 1, …, 10} μ = E[X] = (0 + 1 + ⋯ + 10)/11 = 5 E[X²] = (0² + 1² + ⋯ + 10²)/11 = 35 σ² = E[X²] − μ² = 35 − 25 = 10

For each hacker, the n scores form a trajectory. Welford's update gives that hacker's sampling mean x̄j and sampling variance sj². Across the m hackers, we calculate:

Average sampling mean = (1/m) ∑j=1m x̄j   →   μ = 5 Average sampling variance = (1/m) ∑j=1m sj²   →   σ² = 10

Conclusions

The average sampling mean is close to μ = 5, while the average sampling variance is close to σ² = 10. The results are not exactly equal because only a finite number of hackers is simulated. Both the sample mean and the usual sampling variance with denominator n − 1 are unbiased estimators.

As n increases, the sampling means and variances generally vary less from one hacker to another. For the mean, Var(x̄) = σ²/n = 10/n, so its standard deviation decreases as 1/√n. The sampling variance also becomes more stable when more observations are available.

These properties are useful in inferential statistics because we use sample statistics to estimate unknown population parameters. Larger samples normally produce more precise estimates, with less sampling uncertainty.
